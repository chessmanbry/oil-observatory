# 設計決策

1. **不使用未登記的 Cofacts API**：Cofacts LEGAL.md 要求 API 使用者申請 app-id，並禁止未核准的自動抓取。預設走 dump（Hugging Face，需本人同意協議）；api 模式只在設定 COFACTS_APP_ID 時啟用。
2. **YouTube 廣告／品牌排除半自動**：自動排除付費置入標記；業配字樣只標記「需人工覆核」，品牌官方頻道由人工維護清單，避免誤刪。
3. **規則預標註不計入統計**：只有人工定稿（validated=true）進入 observations；規則對定稿的精確率／召回率寫入可信度報告。
4. **去識別化在入口完成**：處理後資料不含帳號雜湊、網址、電話、@提及；原始 dump 只在本機 data-kevin/raw（忽略版控）。
5. **草稿接口不連網站**：apply 需 --confirm、--editor，並清空審閱，維持「雙方審閱後才公開」。
6. **近兩年期間**：沿用 2024-11-23 至 2026-11-23（台北時間含起訖），可在 company.yaml 調整。
7. **排名依據**仍為已覆核散播筆數；是否分渠道加權待公司與老師確認（未更動）。
8. **Windows 相容**：SQLite 連線改為自動關閉，所有檔案 IO 明確指定 UTF-8。
